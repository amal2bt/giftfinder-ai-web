# 👑 GiftFinder AI — Web Admin Panel & Control Center

The centralized administrative dashboard and management portal for the **GiftFinder AI** ecosystem. Engineered to oversee user accounts, manage end-to-end gift deliveries, monitor AI recommendation and reminder systems, and control real-time application data.

## ✨ Features
- **User & Account Management:** Monitor active accounts, review user statuses, and manage role-based permissions.
- **Gift Delivery & Order Operations:** Track, manage, and oversee gift delivery orders, fulfillment statuses, and scheduling across the platform.
- **AI Analytics & Reminder Oversight:** Monitor AI recommendation generation metrics, usage patterns, and automated AI/user occasion reminder activity.
- **Dynamic Content Control:** Configure gift categories, curation rules, and promotional items in real time.
- **Secure Authentication:** Protected admin routing synced with backend database security policies.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Vite[cite: 1]
- **Backend Sync & Database:** Supabase (PostgreSQL), RESTful API integration
- **State Management & Routing:** React Router, Context API
